# ✅ Gerenciador de Tarefas

Bem-vindo ao **Gerenciador de Tarefas**! 🚀

Este projeto foi desenvolvido para facilitar a organização e o acompanhamento de tarefas diárias, ajudando os usuários a serem mais produtivos e manterem suas atividades sob controle.

---

## 📖 Sobre o Projeto

O **Gerenciador de Tarefas** é um aplicativo web que permite:

- 📌 **Criar, editar e excluir tarefas**
- 📅 **Definir prazos e prioridades**
- ✅ **Marcar tarefas como concluídas**
- 🔍 **Filtrar e pesquisar tarefas**
- 📊 **Visualizar estatísticas de produtividade**

---

## 🛠 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

### **Frontend:**
- ⚛️ **React.js**
- 🎨 **TailwindCSS** para estilização
- 🌐 **React Router** para navegação

### **Backend:**
- 🟢 **Node.js com Express**
- 🗄️ **MongoDB** (Banco de Dados NoSQL)
- 🔐 **Autenticação JWT** para segurança

### **Infraestrutura:**
- 🐳 **Docker** para conteinerização
- 📡 **API REST** para comunicação entre frontend e backend

---

## 🚀 Como Executar o Projeto

### 🔧 **Pré-requisitos:**
Antes de começar, certifique-se de ter instalado:
- **Docker e Docker Compose**
- **Node.js 18+**
- **MongoDB** (caso não use Docker)

### 📦 **Passos para rodar o projeto**

```bash
# Clone o repositório
git clone https://github.com/felipefortu33/gerenciador_de_tarefas.git

# Acesse a pasta do projeto
cd gerenciador_de_tarefas

# Suba os containers com Docker
docker-compose up -d

# Instale as dependências do frontend
cd frontend
npm install

# Rode o frontend
npm run dev
```
O sistema estará disponível em **http://localhost:3000**.
